✨ Features

💀

Spawner ESP

Colored through-wall boxes on spawners — skeleton-first filters (skeleton only / all / custom), player-near-spawner pings with sound, title and chat.

🟩

Chunk Base Finder

Scans loaded chunks (even underground) for player bases and marks them with a green glow + beam to the surface. Villages & trial chambers filtered out.

🟪

Netherite Finder

Ancient debris highlighted in magenta through walls in loaded chunks.

🌀

RTP Hunts

Auto /rtp overworld on a timer (30–600s) hunting a person at a skeleton spawner or a player base — kicks you with SKELETON FOUND / BASE FOUND + coords on the disconnect screen.

⛏️

Area Miner

Select any area (up to 500K blocks), custom width/length/up/down, dig direction, named selections, Fast Mining (Turbo), and Mine-Until-Base that tunnels until it finds a base and mines you inside.

🏗️

Auto Builder

You walk, it builds: Bridge (blocks under your feet), Platform (3×3 floor), and Printer — copy any build and it rebuilds it block by block from your hotbar.

🗿

Attack Escape

When you get attacked (or drop to 5 hearts), a totem jumps to your offhand and /rtp fires to escape.

💰

AH Flipper + Orders

Scans /ah (or /auction), calculates real profit after tax, auto-buys cheap listings, re-lists with /ah sell, and fulfills /orders — endlessly. Server IP & tax settings built in.

👁️

Watcher HUD

Top-corner warning showing who's aiming at you, with names and distances.

📥 How to install

  1. Install Fabric Loader for Minecraft 1.21.11 (fabricmc.net) and the Fabric API mod.
  2. Download the jar from the big green button above.
  3. Put SpawnerFinder-1.21.6.jar in your .minecraft/mods folder — make sure no older spawnerfinder jars are in there.
  4. Start the game and press B.

🎮 Controls

BOpen / close the Spawner Finder menu
F8Toggle spawner ESP
F9Cycle spawner filter (skeleton / all / custom)
[ and ]Set miner area corners (look at a block first)
WASD / jumpStops RTP hunts & alerts (when "Stop When I Move" is on)
/spawnerfinderIn-game commands

⚠️ Notes

Client-side mod: ESP features only see chunks the server has loaded to you. Server anti-xray disguises buried ores/debris as stone, so fully hidden blocks can't be shown by any client. Automation (RTP, AH, mining) talks to the server like a player does — use it on servers where you're okay with that. Always keep only ONE spawnerfinder jar in your mods folder.
